## Causal assessment

Record trigger, mechanism, symptom, contributing factors, confidence and remaining uncertainty. Separate observed timestamps from inferred chronology.

## Correction and verification

Distinguish mitigation, permanent fix and prevention. Link changes if authorized; record before/after regression results, affected checks, missing evidence and release gates. If diagnosis only, give a focused proposed remedy and next experiment.
