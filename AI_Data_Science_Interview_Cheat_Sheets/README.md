# AI and Data Science Interview Cheat Sheets

Revision material for AI Engineer, Agentic AI Engineer, ML Engineer, Applied Scientist, Senior Data Scientist, and Data Science Technical Lead interviews.

The collection is organized in small batches so each topic can be revised independently. Markdown files are the canonical, reviewable sources; combined PDF and DOCX editions are derived reading formats.

## How to use the sheets

1. Read the thirty-second revision at the start of a topic.
2. Reproduce the essential formulas, code patterns, and decision tables.
3. Answer the rapid interview questions without looking at the answers.
4. Practise the lead-level case as a structured five-to-ten-minute response.
5. Use the final checklist to identify gaps for hands-on practice.

For every core concept, be able to explain the intuition, assumptions, trade-offs, failure modes, evaluation, and one production use case. Lead candidates should additionally explain business impact, risk, team decisions, rollout, monitoring, and rollback.

## Evidence and maintenance policy

- Primary papers and official documentation are preferred for changing technical claims.
- Version-sensitive framework behavior must be rechecked before production use.
- Code snippets are intentionally small and educational; they do not replace testing, security review, or workload benchmarks.
- A framework or model name in a sheet is an ecosystem map, not a blanket recommendation.
- The syllabus is broad but not finite; a job description can add domain-specific material.

See `VALIDATION.md` for the checks performed and `PROJECT_LOGIC.md` for the documentation contract.
