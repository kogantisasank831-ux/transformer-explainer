The AlphaLink source in this archive is original project code under MIT. It is independent software and is not made or supported by Sony.

Sony Camera Remote SDK 2.02.00 is a separate dependency downloaded by the user from Sony. No Sony SDK headers, libraries, sample source, API-reference archive or mobile-app binaries are included in this project ZIP. The setup builds an original adapter against that SDK and copies its runtime into the user's local app. Sony's own terms and notices continue to apply to that runtime.

PySide6 6.8.3 / Qt 6 provide the interface. PyInstaller 6.13.0 provides packaging, setuptools provides installation, and pytest 8.3.5 is used for tests. Their applicable licenses and notices are supplied by the installed packages. Before distributing built apps, review those notices and Sony's SDK terms and retain required materials. This archive does not grant rights to third-party dependencies.
